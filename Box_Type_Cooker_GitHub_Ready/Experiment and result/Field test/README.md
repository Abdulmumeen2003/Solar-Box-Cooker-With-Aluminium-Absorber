# Field Test Data and Analysis

This folder contains the three supplied experimental datasets and Python scripts for plotting individual-day readings and comparing the three days.

## Files

- `day1_30min.csv`, `day2_30min.csv`, `day3_30min.csv` — experimental records for three test days.
- `days_plot.py` — plots the Day 3 absorber-plate temperature, ambient temperature and humidity.
- `compare_days.py` — compares the plate temperature, ambient temperature and humidity profiles across Days 1–3.
- `Results/` — saved PNG figures generated by the scripts.

## Expected CSV fields

The analysis scripts expect these column names:

- `Elapsed time (min)` — elapsed test time in minutes.
- `Plate (°C)` — absorber-plate temperature in degrees Celsius.
- `Ambient (°C)` — ambient temperature in degrees Celsius.
- `Humidity` — relative humidity in percent.

The scripts convert these fields to numeric values, remove incomplete rows and sort records by elapsed time.

## Run

From this folder:

```bash
python -m pip install pandas matplotlib
python compare_days.py
python days_plot.py
```

`compare_days.py` saves the three-day comparison figure in `Results/`. `days_plot.py` saves the Day 3 temperature/humidity plot there.

## Interpretation

These are field-test observations. The data should be interpreted in light of the actual test setup and sensor placement. The supplied measurements are empty-cooker/absorber-plate readings, not loaded water-heating or food-cooking tests. No irradiance column is expected by these scripts.

The scripts assume that the CSV headers match the names above. If your source files use different headers, update `COLUMN_MAP` in `compare_days.py` and the column references in `days_plot.py`.
