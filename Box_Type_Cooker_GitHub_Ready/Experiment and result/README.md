# Experiment and Result

This section groups the supplied field-test records and the Python scripts used to inspect and compare the experimental days. The detailed workflow is documented in `Field test/README.md`.

The experimental CSVs contain elapsed time, absorber-plate temperature, ambient temperature and relative humidity. These records are used as experimental observations; they are distinct from the assumed weather profile used by the MATLAB simulation.

For provenance, retain the original source/colleague attribution and experimental conditions when using these records in a report or publication. Do not imply that solar irradiance was measured unless a corresponding measurement file is available.
