# Sensor Data

This directory contains the three supplied experimental CSV datasets (`day1_30min.csv`, `day2_30min.csv`, and `day3_30min.csv`) used by the hardware project and analysis workflow.

The live logger creates additional timestamped session CSV files in this directory. Keep original datasets unchanged; use separate filenames for new experiments.

Check each file's headers, units, sampling interval and experimental date before processing. These files are measurements, not simulation outputs.
