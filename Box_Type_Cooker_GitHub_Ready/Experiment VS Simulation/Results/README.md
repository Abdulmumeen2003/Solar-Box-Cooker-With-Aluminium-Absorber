# Simulation–Experiment Comparison Results

Generated outputs from `Simulation_Experiment.py` and `compare_simulation_all_days.py` are stored here.

## Files

- `Aluminium_Simulation_vs_Day1.png`, `...Day2.png`, `...Day3.png` — simulation and experiment temperature comparisons for each day.
- `Aluminium_Simulation_vs_Day1_Matched_Data.csv`, `...Day2_Matched_Data.csv`, `...Day3_Matched_Data.csv` — time-matched observations and simulation values for each day.
- `Simulation_vs_Three_Days_Bar_Chart.png` — grouped comparison of simulation and all three experimental days at common measurement times.
- `Simulation_vs_Three_Days_Line_Graph.png` — line plot of the same comparison.
- `All_Days_Matched_Temperature_Data.csv` — combined matched temperature dataset.
- `All_Days_Validation_Metrics.csv` — MAE, RMSE, mean bias error and MAPE summary for each experimental day.

These files can be regenerated by running the scripts in the parent directory. CSV files are the numerical outputs; PNG files are presentation figures.
