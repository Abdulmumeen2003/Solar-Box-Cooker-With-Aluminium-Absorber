# Solar Box Cooker: Modelling, Simulation and Experimental Validation

A research and engineering project for studying the thermal behaviour of a reflector-type solar box cooker. The repository brings together a MATLAB thermal simulation, experimental temperature/humidity records, Python analysis scripts, simulation–experiment comparisons, and an Arduino-based monitoring system.

## Project areas

| Folder | Purpose |
|---|---|
| `Model & Simulation/` | MATLAB model, exported simulation data and simulation plots |
| `Experiment and result/Field test/` | Three-day experimental records and plots comparing the field-test days |
| `Experiment VS Simulation/` | Time-aligned comparison of the aluminium simulation with experimental measurements |
| `PlatformIO/Projects/My final year project/` | Arduino firmware, sensor data logger, dashboard and experimental CSV files |

## Quick start

### 1. Python analysis

Use Python 3.10 or later where possible. Install the analysis dependencies:

```bash
python -m pip install numpy pandas matplotlib
```

For the live monitoring dashboard, also install:

```bash
python -m pip install pyserial plotly dash
```

Run scripts from their own directories, for example:

```bash
python "Experiment and result/Field test/compare_days.py"
python "Experiment VS Simulation/compare_simulation_all_days.py"
```

The scripts write generated charts and comparison tables into their respective `Results/` directories.

### 2. MATLAB simulation

Open `Model & Simulation/solar_box_cooker_matlab_simulation_script.m` in MATLAB and run it. The script uses a simplified one-node thermal model and exports predicted time-series and summary CSV files to the MATLAB current working directory.

### 3. Arduino monitoring

Open `PlatformIO/Projects/My final year project/` in VS Code with the PlatformIO extension. Check the serial port in `platformio.ini` and `logger.py` before uploading/running. See that folder's README for wiring and operation details.

## Data and interpretation notes

- The supplied experimental CSV files represent field-test readings. Their column headers and units should be checked before reusing them.
- The MATLAB weather profile and several thermal parameters are explicitly assumptions in the model, not measured weather inputs or experimentally calibrated values.
- The simulation–experiment scripts compare the aluminium prediction with the supplied three-day experimental datasets. They do not establish that every model parameter has been independently validated.
- Experimental and simulation data should be described with their provenance in any publication or thesis. Do not present assumed weather inputs as measured irradiance.
- The supplied experiments are empty-cooker/absorber-plate tests; they should not be described as water- or food-heating tests unless separate loaded-test data are added.

## Reproducibility

Run the scripts from the repository root or any working directory; paths are resolved relative to each script. Keep input CSV files in the locations expected by the scripts. Generated outputs may be regenerated by running the corresponding analysis.

## Limitations

This repository is a project workspace, not a turnkey calibrated commercial cooker design. Confirm hardware wiring, sensor calibration, material properties, weather inputs, and model assumptions before using results for design decisions.
